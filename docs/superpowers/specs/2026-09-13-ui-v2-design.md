# Goal

Perform a **major EpiSignal UI v2 redesign**.

The product should feel like:

**premium global infectious-disease journalism + intelligence**

Visual direction:

* luxury
* minimal
* editorial
* high-information density
* calm
* authoritative
* modern
* not SaaS-dashboard-looking
* not “medical blue dashboard”
* no glassmorphism
* no excessive cards
* no gradients everywhere
* no glowing neon
* no navy dark theme

Think conceptually:

**Reuters Graphics × Financial Times × Monocle × modern epidemic intelligence**

Do not copy any external website directly.

---

# 1. GLOBAL APP STRUCTURE

EpiSignal should have two primary views:

```text
Map
Briefing
```

Navigation should be simple and persistent.

Example:

```text
EpiSignal        Map   Briefing                     Search   Theme
```

Use Lucide icons throughout where appropriate.

Keep navigation restrained.

---

# 2. THEME SYSTEM

Implement:

```text
Light
Dark
System
```

Persist user preference locally.

## Light theme

Main page background must be true white:

```css
background: #FFFFFF;
```

Suggested tokens:

```text
background          #FFFFFF
surface             #FAFAF8
surface-raised      #F5F5F2
text-primary        #111111
text-secondary      #66645F
border              #E6E4DF
```

## Dark theme

Main page background must be true black:

```css
background: #000000;
```

NOT navy.

Suggested:

```text
background          #000000
surface             #0A0A0A
surface-raised      #111111
text-primary        #F5F5F2
text-secondary      #9D9D98
border              #252525
```

Do not use dark blue/navy as the dominant dark theme background.

Semantic disease/status colors may remain colored but should be muted and sophisticated.

# 5. BRIEFING VIEW

Add a dedicated route:

```text
/briefing
```

This is a headline-first surveillance/news feed.

Use Particle-style information density as conceptual inspiration only.

The feed should emphasize:

```text
country/location
event headline
disease group
host sector
source count
updated time
```

Example:

```text
TODAY · 13 SEPTEMBER

DR CONGO                                      42 min
Ebola outbreak expands as response capacity increases
Viral hemorrhagic fever · Human · 7 sources

────────────────────────────────────────────

THAILAND                                       1 h
Dengue activity rises across three provinces
Vector-borne · Human · 4 sources
```

Do NOT use a large card around every item.

Use:

```text
typography
spacing
thin separators
small semantic accents
```

No images are required.

The absence of images is acceptable and should feel intentional.

# 9. EVENT SUMMARY

DeepSeek summary is now:

```json
{
  "title": "...",
  "bullets": ["...", "...", "..."]
}
```

with optional legacy `takeaway`.

Design the page around the new bullet summary format.

Section:

```text
THE BRIEF

• ...
• ...
• ...
```

The summary should be visually central.

Do NOT label everything “AI Summary”.

Do NOT add sparkle/AI icons.

If legacy summaries contain `takeaway`, render them gracefully but do not design the new primary layout around it.
